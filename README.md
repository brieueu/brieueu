## Sobre mim

Tenho interesse em construir soluções que conectam **modelos de IA**, **dados**, **sistemas embarcados** e **arquitetura de computadores**. Gosto de transformar estudos em projetos práticos, documentados e reproduzíveis.

Atualmente, tenho trabalhado e estudado principalmente com:

- 🤖 **Inteligência Artificial e Machine Learning** — experimentos, pipelines, notebooks e avaliação de modelos.
- 🔐 **Agentes LLM e segurança** — uso de MCP para consultas controladas a bancos de dados relacionais.
- 📊 **Dados e simulações** — análise, visualização e modelagem probabilística.
- ⚙️ **Sistemas e baixo nível** — C, estruturas de dados, redes, sistemas embarcados e arquitetura de hardware.
